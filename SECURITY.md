# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

- E-mail: <security@webdeploy.it>
- Machine-readable policy: <https://webdeploy.it/.well-known/security.txt>
- Full policy, including who is responsible and safe harbour: <https://webdeploy.it/security>

Please include a description of the issue and the affected system, URL or component, steps to reproduce
it or a proof of concept, the impact you believe it has, and how we can contact you, and whether you
would like to be credited.

We aim to acknowledge every report within 5 working days and to keep you informed while we investigate
and fix the issue. Please do not disclose the issue until we have released a fix and agreed a disclosure
date with you.

## Supported versions

Only the latest release is supported; the live site always runs it.
