# Italian Writing Style Guide

Reference for writing natural, professional Italian content for WebDeploy news posts.

## Grammar Essentials

### Formal vs Informal
- Use **formal "noi"** (we) for company voice
- Address readers with **"voi"** (you, plural) or impersonal constructs
- Avoid overly stiff bureaucratic Italian

### Article Usage
- Use articles before company names: "la WebDeploy" (optional)
- English acronyms keep English articles: "un API", "il CI/CD"

### Verb Tenses
- Present tense for current features: "Il sistema supporta..."
- Past tense for announcements: "Abbiamo rilasciato..."
- Future for roadmap: "Implementeremo..."

## Tech Writing Conventions

### Keep English Terms
These terms stay in English (italicized if desired):
- open source
- software, hardware
- bug, debug
- deploy, deployment
- commit, push, pull
- framework
- cloud
- server, client
- database
- API, SDK, CLI
- container, Docker, Kubernetes

### Translate These Terms
- feature → funzionalità
- user → utente
- developer → sviluppatore
- update → aggiornamento
- release → rilascio (or keep "release")
- setting → impostazione
- interface → interfaccia
- security → sicurezza
- performance → prestazioni
- privacy → privacy (kept in Italian context)

### Hybrid Approach
Some terms work both ways depending on context:
- "workflow" or "flusso di lavoro"
- "startup" or "start-up" or "azienda emergente"
- "feedback" or "riscontro"

## Sentence Structure

### Avoid Literal Translation
**Bad** (literal): "Siamo eccitati di annunciare..."
**Good** (natural): "Siamo lieti di annunciare..." or "Abbiamo il piacere di annunciare..."

**Bad**: "Questo è qualcosa di cui siamo molto orgogliosi"
**Good**: "Ne siamo molto orgogliosi"

### Passive vs Active
Prefer active voice when possible:
**Passive**: "Il software è stato sviluppato da noi"
**Active**: "Abbiamo sviluppato il software"

### Connectors
Use proper Italian connectors:
- inoltre (furthermore)
- tuttavia (however)
- pertanto (therefore)
- infatti (in fact)
- in particolare (in particular)
- di conseguenza (consequently)

## Punctuation

### Quotation Marks
- Use guillemets for quotes: «testo»
- Or standard quotes: "testo"
- Be consistent throughout

### Lists
- Use bullet points with lowercase start
- No period at end of items unless complete sentences
- Semicolons between items if needed

### Numbers
- Use comma for decimals: 3,14
- Use period for thousands: 1.000
- Dates: 31 dicembre 2025 or 31/12/2025

## Common Mistakes to Avoid

### False Friends
- "actually" ≠ "attualmente" (means "currently")
  - "actually" = "in realtà", "effettivamente"
- "eventually" ≠ "eventualmente" (means "possibly")
  - "eventually" = "alla fine", "infine"
- "sensible" ≠ "sensibile" (means "sensitive")
  - "sensible" = "ragionevole", "sensato"

### Anglicisms
Avoid unnecessary anglicisms when Italian works:
- "performante" → "ad alte prestazioni"
- "customizzare" → "personalizzare"
- "deliverare" → "consegnare", "fornire"
- "skillato" → "competente", "qualificato"

### Gender Agreement
Remember to match adjectives with noun gender:
- "la nuova funzionalità" (feminine)
- "il nuovo aggiornamento" (masculine)
- "le migliori pratiche" (feminine plural)

## Tone Examples

### Announcement (Formal but Warm)
**English**: "We're excited to launch our new feature!"
**Italian**: "Siamo lieti di presentare la nostra nuova funzionalità!"

### Technical Explanation
**English**: "The system uses encrypted connections to protect your data."
**Italian**: "Il sistema utilizza connessioni crittografate per proteggere i vostri dati."

### Call to Action
**English**: "Try it today and let us know what you think."
**Italian**: "Provatelo oggi e fateci sapere cosa ne pensate."

### Problem/Solution
**English**: "Dealing with deployment issues? Our new tool can help."
**Italian**: "Problemi con il deployment? Il nostro nuovo strumento può aiutarvi."

## WebDeploy-Specific Terms

Maintain consistency with existing translations on the site:
- "Developer Manifesto" → "Manifesto dello Sviluppatore"
- "Encrypted Data Storage" → "Archiviazione Dati Crittografata"
- "Managed Infrastructure" → "Infrastruttura Gestita"
- "Linux Workstation Migration" → "Migrazione Workstation Linux"

## Quality Checklist

Before publishing Italian content:
- [ ] Reads naturally to a native speaker
- [ ] Technical terms are used consistently
- [ ] Gender/number agreement is correct
- [ ] No literal translations that sound awkward
- [ ] Punctuation follows Italian conventions
- [ ] Tone matches English version intent
- [ ] No anglicisms where Italian alternatives exist
